# Het Gesprekswiel – oefenapp

Interactieve oefenapp bij het gesprekswiel (Van den Berg & Kanters, 2018, *Gesprekken die werken*) voor eerstejaarsstudenten HBO-rechten.

Zes oefenbare knoppen: elkaar uit laten praten, luisteren, vragen stellen, omgeving, non-verbale communicatie en emoties/gevoelens. Elke knop heeft een startvraag, een aan/uit-schakelaar met effecten, en een trek-functie met vijf manieren. De middercirkel geeft willekeurige gespreksstarters.

## Lokaal draaien

```bash
npm install
npm run dev
```

## Publiceren via GitHub Pages

Een push naar `main` triggert automatisch de workflow die de app bouwt en naar GitHub Pages deployt. Zet in **Settings → Pages → Source** de optie **GitHub Actions** aan.
